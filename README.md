# Inner-Time 内经时间
A Huangdi Neijing calendar that combines Ganzhi, solar terms, and the lunar calendar, turning each day and hour into seasonal wellness guidance from the classic.
一个以黄帝内经为知识库的日历系统。从四季/节气/阴阳/昼夜/时辰的角度给出内经相关的实时养生提示。
